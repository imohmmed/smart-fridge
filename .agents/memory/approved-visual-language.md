Future UI changes should preserve the existing Smart Fridge visual language: soft rounded surfaces, balanced spacing, warm light mode, readable charcoal/slate dark mode, restrained transparency, and clear RTL/LTR behavior across responsive breakpoints.

**Why:** The user explicitly approved the current design and asked that future changes keep it consistent.

**How to apply:** Scope new page-specific styling, reuse the existing spacing and radius language, avoid broad shared overrides, and verify Light/Dark plus Arabic/English at phone and desktop widths before delivery.

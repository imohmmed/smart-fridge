---
name: Approved Smart Fridge visual language
description: The user-approved visual baseline to preserve when extending the Smart Fridge app.
---

Future UI changes should preserve the existing Smart Fridge visual language: soft rounded surfaces, balanced spacing, warm light mode, readable charcoal/slate dark mode, restrained transparency, and clear RTL/LTR behavior across responsive breakpoints.

**Why:** The user explicitly approved the current design and asked that future changes keep it consistent.

**How to apply:** Scope new page-specific styling, reuse the existing spacing and radius language, avoid broad shared overrides, and verify Light/Dark plus Arabic/English at phone and desktop widths before delivery.

The login screen follows the same language with a compact layout, muted sage/slate surfaces, restrained illustration color, and no saturated gold or cartoon-like accent blocks.

**Why:** The user requested a calmer login presentation with less copy and less empty space, comfortable in both themes and languages.

**How to apply:** Keep the login hierarchy short, preserve the small refrigerator brand mark, and use the login theme toggle to verify both light and dark states.

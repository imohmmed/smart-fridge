Fix these two issues:

=== 1. NUMBERS - USE ENGLISH/WESTERN NUMERALS ===

Replace ALL Arabic-Indic numerals (٠١٢٣٤٥٦٧٨٩) 
with Western Arabic numerals (0123456789) everywhere.

Add this to your CSS:
* {
  font-variant-numeric: normal;
}

Add this to your JavaScript - run it on all displayed numbers:
function toWesternNums(str) {
  return String(str).replace(/[٠-٩]/g, 
    d => '0123456789'['٠١٢٣٤٥٦٧٨٩'.indexOf(d)]
  );
}

Apply toWesternNums() to EVERY number before displaying it:
- Calories numbers
- Water cups counter
- Quantity badges on fridge items
- Shopping list quantities
- Date fields
- Percentage numbers
- Temperature display (4°C / -18°C)
- Progress bars values
- Any input that shows numbers

Also add to HTML head tag:
<meta charset="UTF-8">
